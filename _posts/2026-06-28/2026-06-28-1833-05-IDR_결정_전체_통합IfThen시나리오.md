## Why-First (3문장 전략 방향)

1. **총체적 리스크-오프**: KOSPI 6/26 서킷브레이커(5.81%↓) + 외국인 일간 4.6조 이탈 + 환율 1,535원 = 전체 포트폴리오 방어 모드 전환. 반도체 쏠림 리스크 현실화.

3. **시나리오별 전략 차별화**: 1) 금주 반등 시 관찰 위주 vs 2) 추가 급락 시 일부 대응 vs 3) V자 반등 시 추세 전환 확인. 확신이 없는 국면에서는 현금 비중 유지가 최선.

## 🧩 If-Then 시나리오

### 시나리오 S1: 단기 반등 (40% 확률)

**조건**: ① 삼성 1,000조 발표 긍정 반응 (6/29) ② 외국인 순매도 감소 ③ S&P 500 7,300선 유지

| 구분 | 내용 |
|------|------|
| **KOSPI 목표** | 8,400→8,800 (+4.8%) |
| **기간** | 6/29~7/3 |
| **주도주** | 삼성전자(1,000조 수혜), 반도체(기술적 반등), 건설(메가 프로젝트) |
| **전략** | 📌 현금 비중 유지하며 반등 시 관찰. 기존 포지션 분할 매도 기회 활용 |
| **대응** | 반도체 비중 과다 시 일부 축소. 신규 진입은 관찰 |

### 시나리오 S2: 추가 급락 (35% 확률)

**조건**: ① 미-이란 충돌 재확전 (호르무즈 봉쇄) ② 외국인 추가 이탈 ③ 환율 1,550 돌파

| 구분 | 내용 |
|------|------|
| **KOSPI 목표** | 8,400→7,800~8,000 (-5~7%) |
| **기간** | 6/29~7/10 |
| **주도주** | 방어주(통신·백화점·생활소비재)·인버스 ETF(참고용) |
| **전략** | 📌 현금 비중 60%+ 유지. 7,800~8,000 구간에서 분할 대응 준비 |
| **대응** | KODEX 200 동일가중(분산) 분할 매수 검토. 반도체 비중 확대는 추가 하락 후 |

**조건**: ① 미-이란 휴전 협상 재개 ② SK하이닉스 ADR 수요예측 호조 ③ 외국인 순매수 전환

| 구분 | 내용 |

| **주도주** | 반도체(삼성전자+SK하이닉스), 2차전지(동반 반등) |
| **전략** | 📌 반등 확인 후(2거래일 연속 상승+외국인 순매수) 추세 전환 판단 |
| **대응** | 추세 전환 확인 시 반도체·2차전지 분할 비중 확대 |
