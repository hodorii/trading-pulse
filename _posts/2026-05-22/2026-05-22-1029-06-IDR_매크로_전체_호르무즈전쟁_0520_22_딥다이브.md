## 5. 美 정치 상황 — 하원 전쟁권한결의안 취소의 의미

### War Powers Resolution (전쟁권한결의안)

| 내용 | 상세 |
|------|------|
| **발의** | 민주당 주도, 소수의 공화당 이탈표 합류 |
| **내용** | 트럼프 대통령에게 이란에서 미군 철수 요구 |
| **예상 결과** | 초당적 지지로 통과 예상 (통과 시 트럼프 정치적 타격) |
| **실제 결과** | **공화당 지도부, 표결 자체를 취소** — 패배 인정 |
| **연기** | 6월 메모리얼데이 휴회 이후 재추진 |
| **민주당 반응** | "겁쟁이들(cowardly)" — 낸시 펠로시 등 |

### 정치적 시사점

```
트럼프의 이란전쟁 수행에 대한 의회 견제 실패
  → 단기: 트럼프 자유로운 군사 작전 지속 가능
  → 중기: 6월 결의안 재표결 = 불확실성
  → 장기: 여론이 반전(反戰)으로 기울 경우 트럼프 부담 증가

한국 관점:
  • 의회 견제 실패 = 駐韓 미군의 이란 전쟁 관여 리스크 유지
  • BUT 한국은 직접 전투 참여 안 함 = 우회적 영향
  • 원화 약세 + 유가 급등이 더 직접적 충격
```

## 8. 핵심 결론

### 이 전쟁이 끝나려면?

```
① 우라늄 문제 해결 (가장 어려움) — 이란 우라늄 반출 = 주권 포기
② 호르무즈 통행권 — 이란의 유일한 레버리지, 포기 어려움
③ 제재 해제 — 트럼프가 전쟁 후 제재 풀면 정치적 손해

→ 단기 타결 가능성: 낮음 (15~20%)
→ 장기 교착: 높음 (50%+)
→ 재확전: 중간 (30%)
```

### 한국 투자자 관점

```
1. 유가 $100+가 뉴노멀 → 정유·방산·원전 수혜, 항공·해운 악재
2. 원화 약세 1,500+ 지속 → 달러 자산 보유 유리
3. 전쟁 장기화 = 글로벌 경기 둔화 → 성장주보다 가치주 우선
4. 6월 전쟁권한결의안 재표결 = 정치적 변수 모니터링 필요
5. 주말 동안 트럼프 Truth Social 발언 = 가장 큰 단기 변수
```
